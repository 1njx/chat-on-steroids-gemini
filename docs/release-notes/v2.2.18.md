## 2.2.18 Gemini edition: thinking levels read per model

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).
- Keep a Gemini tab open in your own browser: the app reads each model's thinking levels again
  once by itself. While it does, Gemini's model picker switches models for about 3.5 seconds and
  then goes back to the one you had.

### 🐛 Fixed

- The thinking slider offers only the levels Gemini offers with the picked model, and none for
  Auto, so "That thinking level is not offered for the selected model" no longer fires for a
  level the app offered.
- Choosing a model or a level no longer fails when Gemini's picker ignores the first click.
