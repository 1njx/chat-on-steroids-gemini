## 2.2.15 Gemini edition: the Gemini app reconnects by itself

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### 🐛 Fixed

- When the tunnel address changes, the app adds Chat On Steroids Core in Gemini again by itself,
  also when Gemini uses the Core quick tunnel (before, only with Gemini's own tunnel beside
  OpenAI's), so you no longer need Settings for it.
- A re-add that fails or never finishes is tried again 2 minutes later, 3 tries in all per
  address. Settings → Gemini says when.
