## 2.2.4 Gemini edition: Gemini's tunnel no longer replaces ChatGPT's

Set up Gemini no longer disconnects ChatGPT. See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).
- If Set up Gemini switched your app to Cloudflare, open Settings → Providers → Gemini → Tunnel
  and press **Switch ChatGPT back to the OpenAI tunnel**. If no tunnel ID is saved, Setup asks for
  it: paste the Core tunnel ID from platform.openai.com → Tunnels again, and the Desktop and
  Plugins IDs if you use them.
- Gemini's quick tunnel gets a new address on every start: add the app in Gemini again with it.

### 🐛 Fixed

- **Gemini gets its own tunnel.** On the OpenAI Secure Tunnel, "Start a tunnel for Gemini" runs a
  Cloudflare quick tunnel for Gemini next to it. ChatGPT stays on the OpenAI tunnel. "Turn off
  Gemini's tunnel" stops only Gemini's.
- **Plugins page wording.** On a Cloudflare or own tunnel it says "Not connected" or
  "Online · ChatGPT needs the new address" instead of "Setup required".
- Switching the tunnel kind keeps the saved tunnel IDs.
