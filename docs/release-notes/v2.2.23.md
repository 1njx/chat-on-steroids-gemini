## 2.2.23 Gemini edition: new chats while another one waits

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### 🐛 Fixed

- A new chat no longer fails with "no-ready-gemini-page" while another Gemini chat is still running
  (for example waiting for you to allow a tool). Another Gemini tab takes it, and when every tab is
  busy a new Gemini tab opens for it.
- "That Gemini model is not available on this account" no longer appears for a model you have, right
  after a new chat starts in a Gemini tab that was never on screen.
