## 2.2.17 Gemini edition: chats from the app reach Gemini, with the Core app

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).
- Keep Gemini signed in in your own browser (the one with the extension). Google does not allow
  signing in inside the app's built-in browser, so Gemini always runs in yours.

### 🐛 Fixed

- Messages to Gemini from the app's chat no longer wait 3 minutes and fail when chats use the
  built-in browser: Gemini is no longer opened there, and a Gemini tab on custom apps can now take
  a message by opening a new chat.
- App chats @-mention Chat On Steroids Core by default once the app is added in Gemini, so Gemini
  can use your folders.
- "Add it in Gemini for me" no longer fails `verify-failed` (or deletes the right app) because
  Gemini first showed an old cached address.
