## 2.3.0 Chat On Steroids is now Gem Web Code

### 👉 After updating

- Reload the browser extension (its version moves with the app). It is now called "Gem Web Code
  browser extension".
- In Gemini, the app's custom app becomes "Gem Web Code Core". Until it is renamed, messages keep
  mentioning your existing "Chat On Steroids Core". "Add it in Gemini for me" (Settings → Gemini),
  or the next tunnel address change, replaces it with "Gem Web Code Core".

### ✨ Changed

- The app is now **Gem Web Code**, focused on Google Gemini; ChatGPT keeps working as before.
  The window, installer, Start menu, extension, Settings and docs use the new name in every
  language.
- Your chats, settings and shared folders stay where they are, and the update installs over the
  old version.
- ChatGPT connectors keep their names ("Chat On Steroids Core", "Desktop" and "Plugins"), so
  nothing needs to be added again in ChatGPT.
- The project moved to [github.com/1njx/gem-web-code](https://github.com/1njx/gem-web-code). Old
  links redirect, and updates keep arriving.
