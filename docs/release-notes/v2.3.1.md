## 2.3.1 Plugins follow you into Gemini

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### 🐛 Fixed

- Re-adding Core in Gemini no longer ends with "Gemini's custom apps did not show exactly one app
  with this name and address". The app was added fine, but Gemini calls it "Chat On Steroids Core"
  and the check looked for "Gem Web Code Core", so every retry deleted and re-added it. Both names
  now count as the same app.

### ✨ Added

- Your plugins are added in Gemini by themselves: once you have plugins and Gemini has Core, the app
  adds "Chat On Steroids Plugins" in Gemini's custom apps, and again whenever the tunnel address
  changes, so a restart no longer leaves Gemini on an old Plugins address.
