## 2.2.11 Gemini edition: old Core apps deleted before adding

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### 🐛 Fixed

- "Add it in Gemini for me" now finds every Chat On Steroids Core app already in Gemini. It
  deletes each one with an old address, and any duplicate, before it adds the new one. One with
  this address is kept and nothing is added. Before, only the first app with exactly that name was
  checked, so duplicates stayed and a second copy made the delete fail.
- Names match in any case, with `-` or `_` for spaces and a duplicate's "(2)".
