## 2.2.6 Gemini edition: the ChatGPT plugin created for you

See [docs/setup.md](docs/setup.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).
- In Setup → ChatGPT, press **Add it in ChatGPT for me** on a plugin's card.

### ✨ Added

- **Add it in ChatGPT for me**: the extension opens ChatGPT's Plugins page, fills in Add custom MCP
  server (name, description, tunnel or URL, No authentication), ticks "I understand and want to
  continue" for you and clicks Create as a plugin. A plugin with the same name is left as it is.

### Limits

- Only ChatGPT in English. Another language, or a dialog that looks different, gets nothing created
  and the card says to use the steps by hand.
- Allowing all tools and the first tool call's prompt are still yours to click.
- Checked on the live dialog up to an enabled Create button; the first real use is the first Create.
