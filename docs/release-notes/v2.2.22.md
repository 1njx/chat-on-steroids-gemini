## 2.2.22 Gemini edition: tool approvals are not answers, and Full access

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### 🐛 Fixed

- Gemini's "Let Gemini use … ? Don't allow · Allow once · Always allow" card no longer shows up as
  Gemini's answer in the app's chat. The chat waits for your choice in the Gemini tab, which comes to
  the front, and then records the real answer.

### ✨ Added

- **Settings → Gemini → Full access** (off by default): presses Gemini's **Always allow** for you on
  this app's tool approvals, so Gemini runs the app's tools, commands included, without asking.
  Other apps' approvals are left to you.
