## 2.2.14 Gemini edition: "Add it in Gemini for me" opens your default browser

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### 🐛 Fixed

- "Add it in Gemini for me" opens Gemini's custom apps page in your default browser, in front (only
  that page, never the Core address), and the extension does the steps there.
- An already open custom apps tab is brought to the front instead of a second one being opened. The
  extension opens one itself only when no page with the extension reported within 15 seconds.
- When no Gemini page with the extension takes the work, Settings → Gemini says "Open Gemini in the
  browser that has the Chat On Steroids extension." instead of failing silently.
