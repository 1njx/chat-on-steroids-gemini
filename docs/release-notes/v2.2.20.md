## 2.2.20 Gemini edition: the app's chat works with Gemini in the background

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app). Open Gemini tabs get the fixes on
  that reload; a tab opened afterwards has them from the start.
- Gemini tabs no longer go to sleep in Edge while they are open, so the app can use them while you
  work in it.

### 🐛 Fixed

- Messages from the app's chat to Gemini go through while Gemini's tab is covered or in the
  background: Edge no longer freezes the tab, and the answer reaches the app without opening the tab.
- Sends with the Chat On Steroids Core app no longer fail "Gemini did not offer a connected app with
  that name" (Gemini changed how an @-mention looks).
- A model read no longer runs during a send and breaks it.
- A sent message no longer comes back into the app's message box.

### Known

- Gemini sometimes stops an answer after using the Core app with "Something went wrong (4)", although
  the app's tool replied correctly. That happens inside Gemini.
