## 2.2.16 Gemini edition: old copies always deleted first, and checks before trying it

See [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).
- Press "Add it in Gemini for me" once, so the app checks Gemini's list.

### 🐛 Fixed

- The old Chat On Steroids Core app is always deleted before the new one is added. An app whose
  card showed a description was not found before, so it was left in place.
- After adding, the app checks that Gemini's list shows exactly one app with the name, holding the
  new address.

### ✨ Changed

- The Add step is done only when four checks pass: the address answers through the tunnel, Gemini
  has the app once with this address, Gemini connected to it, and Gemini listed its tools.
