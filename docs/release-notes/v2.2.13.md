## 2.2.13 Gemini edition: setup in front, with a status panel

See [docs/setup.md](docs/setup.md) and [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### 🐛 Fixed

- Setup pages open in front: ChatGPT's plugin pages, platform.openai.com and Gemini's custom apps
  open in your own browser window as the active tab, with the window focused (and restored if it
  was minimized). A covered or minimized page barely loads, which made setup fail with "The page
  did not finish this step" or "Gemini did not finish in time". Chats still open in the background.
- The Gemini app follows a new tunnel address: a quick tunnel gets a new address at every start, so
  once the app was added and Gemini's tunnel is on, a new address adds it again by itself, once per
  address. Settings → Gemini says so and how it went.

### ✨ Added

- A status panel on the setup page while the extension works there: please don't click or type in
  that tab until it says done. It shows each step, then done (green) or the exact error (red, the
  same words Setup shows). It never shows an address or key.

### Limits

- The automatic re-add opens Gemini's custom apps in front of your other windows when the address
  changes.
