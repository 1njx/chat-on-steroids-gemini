## 2.2.25 Gemini answers keep their formatting, and clearer usage limits

### 👉 After updating

- Reload the browser extension (its version moves with the app).

### ✨ Changed

- While Gemini answers, your message shows as a bubble with animated typing dots under it.
- Gemini answers keep their code blocks, tables, lists and headings. Images and videos Gemini adds
  leave a line naming them, because the app cannot show them.
- The composer says "Gemini Auto" instead of "Auto", so it is not confused with ChatGPT's Automatic.
- Settings → Gemini no longer has its own "Send to Gemini" form; send from a chat with a Gemini
  model picked. "Recent Gemini messages" still lists how each send went.

### 🐛 Fixed

- A Gemini model at its usage limit showed a broken name such as "Gemini 22 PM". It now shows when
  the limit resets, and the list of models is read again until it does.
- A message Gemini never received disappeared. It now goes back into the message box.
- A second message in a new Gemini chat, sent before the first answer arrived, started a separate
  Gemini chat. It is now refused until the first answer arrives.
- "Browser extension not connected" flashed on every start while the extension was still
  connecting.
