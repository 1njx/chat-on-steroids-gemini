## 2.2.7 Gemini edition: setup done for you in your signed-in tabs

See [docs/setup.md](docs/setup.md) and [docs/gemini.md](docs/gemini.md).

### 👉 After updating

- Reload the browser extension (its version moves with the app). It now also runs on
  platform.openai.com, only in a tab it opened for setup.
- In Setup, pick a folder and the access level, then press **Set everything up**.

### ✨ Added

- **Set everything up**: tunnel + key → Connect → plugins in ChatGPT with Allow all tools → Gemini
  when its tunnel is on, each part with its own progress and a plain fallback.
- **Set it up for me** in the Tunnel and Key steps: a tunnel and a Restricted key (Tunnels: Read and
  Use) at platform.openai.com. The key goes only into the system's secret store.
- **Allow all tools** set after "Add it in ChatGPT for me" creates a plugin.
- A tool call of **this app's own plugins** is allowed at once; other plugins are never answered.
- **Add it in Gemini for me** deletes an app with an old address, clicks Next, ticks the notice and
  Connects.

### Changed

- ChatGPT's Add button and menu item are matched in every language Setup shows.

### Limits

- ChatGPT cannot edit a plugin's address: a quick-tunnel plugin with an old address must be deleted
  in ChatGPT and added again. Use an OpenAI tunnel or your own HTTPS tunnel to keep the address.
- platform.openai.com and Gemini are matched in English only.
- Never pressed on a live account while testing: Create (tunnel), Create secret key, Create as a
  plugin, Allow all tools (it was already set), Allow once on an approval card, Delete and Connect in
  Gemini. Each flow was run on the live pages up to that click, with the click blocked.
